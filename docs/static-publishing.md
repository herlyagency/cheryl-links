Public content and uploaded media are exported into GitHub Pages at deployment. Admin Publish saves to Supabase; the hourly deployment picks it up (GitHub schedules may be delayed), or run Actions → Deploy to GitHub Pages → Run workflow. Scheduled link starts also require an export. Failed exports do not replace the previous deployment. Initial deployment requires Supabase to be accessible; quota restriction must first clear. Analytics and live detection still use Supabase and may be unavailable during restrictions. Uploaded images are resized to 1200px and compressed when smaller; existing images are copied unchanged. No service-role key is needed.
